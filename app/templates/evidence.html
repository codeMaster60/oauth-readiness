How every claim is tagged

✅ testedA person actually did it in the provider's console during this project (see setup attempts below).
🛰️ probed liveThe agent made an anonymous request to the provider's real endpoint and observed the behaviour.
📄 official docsStated in the provider's own documentation. For generated guides, the supporting quote was found word-for-word on the fetched page.
🔗 third-partyOnly a non-official source says it (vendor blog, integration platform docs).
⚠️ uncertainInferred, contradictory, or the model's "quote" was not on the page. Don't rely on it without checking.

Partner-gated or discretionary access+2
